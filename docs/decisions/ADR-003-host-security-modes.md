# ADR-003：保护未批准记录，明确已批准记录的暴露边界

2026-10-12。受控电脑的单条暴露边界已由用户确认；手机端具体策略随整体方案评审。

受控电脑可以捕获当前使用的密码、存入的新密码和会话。设计目标是在手机未失陷、恢复材料未泄露、用户核对有效的条件下，保护其他未批准凭据。

手机每次确认一个记录版本，可以限制设备可申请的记录或完全禁止向特定设备释放高价值账号。该策略在手机执行；桌面安全模式标签与设备签名不证明主机安全。

不再承诺通用“高保证模式”或 Passkey 提供方。网站原生无密码登录可作为外部选择，但不能保证受控电脑会话安全。响应超时、删除引用和吊销配对均不能收回已经得到的秘密。
