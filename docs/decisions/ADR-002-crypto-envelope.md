# ADR-002：逐条版本密钥与公钥收件方信封

2026-10-12。用户已确认单条保护目标、约 56 字符码与离线恢复；算法套件及具体实现为提交审核的工程推荐。

每条凭据每次更新生成独立随机 256 位数据密钥，使用 AES-256-GCM。通过标准 HPKE 分别封装给手机和离线恢复公钥，电脑可仅持公钥保存新密码，无需获得整库私钥。

手机硬件解密与签名私钥分离。约 56 字符码释放当前版本数据密钥，不承诺一次性或自动过期；会话加密文本仅释放所需字段。公钥加密本身不证明来源，手机另行核验记录和版本。

匹配目录独立加密，目录密钥可授权给电脑，仅打开域名/非敏感别名。恢复材料与密文备份分开保存，账号不参与密钥派生。P-256 整体传统安全基线约 128 位，非抗量子方案。
