# ADR-001：无需自建授权中继

2026-10-12。用户已确认离线扫码与长返回码，并允许自行使用通信工具；具体应用协议待整体评审和技术验证。

手机扫描电脑请求，电脑接收约 56 字符版本解密码。工具传递时推荐会话加密文本，文本更长但可粘贴。电脑不需要摄像头，产品不自动发送消息或读取通信工具内容。

手机提醒本地执行。完整密文库通过用户指定存储联网同步，默认 Google Drive；账号仅下载密文，恢复由离线密钥完成。无需自建中继、推送或强制在线恢复服务。

“可离线授权”不表示浏览器同步或用户选择的通信工具也离线。已缓存记录可以扫码解密，初始化配对需要完成真实的公钥交换。

详见 [协议](../protocol.md) 和 [存储恢复](../storage-and-recovery.md)。
