## 1. 密钥职责

| 密钥 | 持有方 | 能力 |
| --- | --- | --- |
| 手机解密私钥 | Android Keystore；候选 P-256 | 打开封装给该手机的密钥，正常 App 逐条审批 |
| 手机签名私钥 | 独立硬件密钥 | 签署配对、核验凭证与会话响应 |
| 恢复私钥 | 用户离线材料；恢复时仅进入可信环境 | 恢复该库记录与目录，是明确的全库授权路径 |
| K_record | 每条记录每次更新新生成 256 位随机值 | 只解开当前凭据版本；电脑保存/使用时短暂可见 |
| K_directory | 手机/恢复信封；经配对授权的电脑可持有 | 打开域名/非敏感别名目录，不能解开任何凭据 |
| 电脑设备私钥 | 每个安装独立持有 | 请求身份；不是主机安全证明 |
| 电脑临时会话私钥 | 每次会话新建 | 打开本次会话密文响应；正常客户端不持久化 |

目录密钥不属于凭据主密钥。电脑不能持有手机私钥、恢复私钥或批量解开凭据的共享秘密；不能为了方便把恢复材料放入云同步。

## 2. 标准算法候选

- 凭据 AEAD：AES-256-GCM，96 位 nonce；每次内容更新新密钥，同一 key/nonce 绝不重用。重试上传复用既有密文，不使用同一 nonce 加密改变后的内容。
- 收件方信封：RFC 9180 HPKE，候选 DHKEM(P-256, HKDF-SHA256)/HKDF-SHA256/AES-256-GCM。使用标准实现和向量；Android 不可导出私钥的 KEM 接口需真机验证。
- 认证：独立 P-256 ECDSA-SHA-256，严格规范化编码、域隔离和签名解析。
- 目录：独立 AES-256-GCM；为目录版本/对象明确 nonce 分配与更新上限，禁止多设备使用可能冲突的本地计数器。原型冻结具体格式前验证规则。
- 口令保护恢复文件：Argon2id，随机盐和参数存入外层头，参数经 Android 14 基准测试确定；高熵恢复密钥仍是安全根。
- 随机性只来自平台 CSPRNG。所有解析、对象大小和算法标识受限，未知必需版本/套件必须拒绝，不降级到弱套件。

P-256 传统安全强度约 128 位，不宣称整体 256 位或抗量子。HPKE 不自行提供记录来源认证、应用重放/回滚防护，也不对长期接收私钥失陷提供历史密文前向保密。

## 3. 记录与可信显示

公钥加密只证明对象可由手机解密，不能证明对象来自可信保存方。手机签署的核验摘要必须绑定库、记录、版本、可信站点内容、密文摘要及必要收件方信息；初始公钥固定和更换操作必须明确确认。

手机对已见记录保留可信摘要和版本关系。新记录/新版本显示未核验状态，不把服务器最新时间当作可信版本。手机没有见过的历史、重装后未恢复的检查点及离线其他手机的状态不能得到完整回滚保证。

目录只用于电脑寻找候选，不是手机可信显示依据。手机从凭据信封内读取站点和账号并核对授权；电脑上报的当前 URL 仍不可用于证明受控终端实际访问了该站点。

## 4. 两种返回方式

### 约 56 字符版本解密码

输出当前 K_record 的 Base32 编码及输错校验，约 56 字符。它不绑定某一次挑战、不自动过期，可重复打开该记录版本；批准后用户可自行复制或传递。该模式释放整个凭据 payload，因此未来 TOTP 种子、私密备注等必须另设密钥/授权单元。

### 会话加密响应

推荐工具回传时使用。手机用标准 HPKE 把当前用户名/密码字段加密给请求中的临时公钥，签名绑定完整请求摘要和响应密文。只返回所需字段，不返回 K_record。中间渠道取得密文不应获得凭据，但获批电脑仍可以保留临时私钥、响应和明文。

两种格式明确区分，禁止验签失败后按原始解密码解释。手机从获授权请求选择返回格式，不由未验证 UI 字符串决定。

## 5. 硬件、认证与秘密生命周期

- 每次释放有手机本地明确确认；生物识别/系统凭据应绑定真实密钥使用授权，不能仅把 local_auth 返回布尔值作为安全边界。
- 解开内容以显示可信账号和最终释放的交互顺序、每次操作认证及允许的系统凭据组合，由硬件原型确认。禁止因为手机已解锁就给电脑批量授权。
- 手机长期私钥不可导出，但本条 K_record、解密结果和手输码会进入 App 可见内存；不声称所有秘密从不离开硬件。
- JavaScript/Dart 等托管内存不保证即时擦除。缩短驻留、清理状态、避免日志/URL/崩溃上传中的秘密，不保证管理员不能读内存。
- 复制/粘贴由用户主动触发，不自动发消息或监听剪贴板。分享优先密文，清理不能删除聊天服务及系统历史。

## 6. 恢复、撤销与轮换

账号只用于取得密文；持有完整备份和离线恢复材料即可恢复。普通备份不得含恢复私钥，单独恢复文件不得被误当作完整数据备份。

恢复创建新硬件密钥并重封装；不能导出旧手机硬件私钥，也不能使旧密文和已释放密码失效。修改网站密码时新建凭据版本与独立数据密钥。

手机删除电脑配对后拒绝其后续请求；没有网络的其他手机不会即时知道。设备私钥被复制后无法区分原机与克隆，撤销整个身份；不承诺无服务器环境下远程即时清除。
